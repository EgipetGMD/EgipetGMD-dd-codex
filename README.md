# D&D Codex — Cloudflare starter

## Что уже есть
- Пергаментный интерфейс и категории.
- Одна кнопка создания записи (дублирующая кнопка удалена).
- Регистрация, вход, выход и cookie-сессии.
- D1 API для общей библиотеки.
- Публикация хоумбрю после входа; автор может удалить свою запись.
- PBKDF2-SHA256, 100 000 итераций; в БД хранятся хеш и соль, а не пароль.

## Важно
Это стартовая версия инфраструктуры, не полный каталог D&D. Карточки в `public/app.js` помечены как демонстрационные примеры. Следующий этап — импорт лицензированного SRD-контента и отдельные структурированные поля для каждой категории. Сейчас публикация хоумбрю открыта всем зарегистрированным аккаунтам; модерация и роли ещё не реализованы.

## Локальная разработка
1. Установи Node.js LTS.
2. `npm install`
3. Создай D1: `npx wrangler d1 create dd-codex`
4. Впиши выданный `database_id` в `wrangler.jsonc`.
5. Примени миграцию: `npm run db:migrate:remote`
6. `npm run dev`

Для локальной D1 используй `npm run db:migrate:local`.

## GitHub + Cloudflare
1. Создай GitHub-репозиторий `dd-codex` и загрузи содержимое этой папки в корень репозитория.
2. В Cloudflare Workers & Pages создай Worker `dd-codex` и привяжи D1 database к binding `DB` (database name `dd-codex-db`).
3. Для Git-деплоя подключи репозиторий в Cloudflare Workers Builds, либо деплой через `npm run deploy`.
4. Убедись, что в Worker доступен static assets binding `ASSETS`.
5. Проверь `/api/health`, регистрацию и создание записи.

## Текущие ограничения
- Нет email-подтверждения, сброса пароля, rate limiting и модераторской панели.
- Демо-каталог не является полным SRD.
- `data_json` зарезервирован для будущих структурированных характеристик.
- Перед публичным запуском добавь антиспам и модерацию, а также проверь настройки домена и резервного копирования D1
